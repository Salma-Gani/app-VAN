Date : 2026-10-20 · Suite au diagnostic du Lot 1 (`audit_lot1_2026-10-20.md`)

Ce document décrit **uniquement ce qui a été réellement codé et testé** dans cette
itération. Chaque point renvoie au fichier concerné. Les limites restantes sont

## P1 — Fiabilité des données

### 1. Change : plus aucun taux inventé
- `ecoinvest/data/market.py` : `fx_rates()` ne complète plus les devises manquantes
  avec `FX_FALLBACK`. Seuls les taux réellement récupérés sont renvoyés.
- `ecoinvest/utils/formatting.py` : `convert_from_mad` / `convert_to_mad` renvoient
  `None` si le taux est absent, au lieu d'appliquer un forfait.
- `ecoinvest/ui/pages/shared.py` : en cas d'échec, seul `{"MAD": 1.0}` est renvoyé.
- `ecoinvest/config.py` : `FX_FALLBACK` est conservé mais documenté comme **indicatif
  et jamais utilisé comme donnée réelle**.
- Effet : une conversion EUR/USD sans taux live s'affiche « — », jamais une valeur
  inventée.

### 2. Univers de repli dédupliqué
- `ecoinvest/data/bvc.py` : suppression des doublons `SID` (×3) et `IMO` (×2) de
  `_FALLBACK_UNIVERSE`. Contrôle : 77 symboles, 77 uniques.

### 3. Erreurs réseau rendues visibles
- `ecoinvest/data/http.py` : nouvelle fonction `record_exception(provider, error)`.
- Utilisée dans :
  - `bvc.fetch_universe_live` (univers BVC) ;
  - `market._download` (Yahoo Finance) ;
  - `news.fetch_all_news` (chaque flux RSS, nommé) ;
  - `fundamentals.market_reference` (référentiel BVC).
- Ces erreurs apparaissent désormais dans la page **Sources** (`http.diagnostics()`),
  au lieu d'être avalées par un `except: pass`.

### 4. Bug d'exercice corrigé (Lot 1, rappel)
- `statements.record_issues()` / `store_issues()` + seed TMA 2023 corrigé +
  colonnes « Exercice AAAA » dans l'UI.

## P2 — Simulateur

### 5. Frais réellement pris en compte
- `ecoinvest/analytics/forecast.py` :
  - `portfolio_fan_chart(..., annual_fee, contribution_fee)` ;
  - `projection_table(..., annual_fee, contribution_fee)`.
- `ecoinvest/ui/pages/simulator.py` : deux curseurs « Frais par versement (%) »
  (défaut 0,60 %, paramètre `BROKERAGE_FEE`) et « Frais annuels de gestion (%) ».
  Les frais réduisent le rendement et chaque versement ; le capital versé affiché
  reste le montant brut payé.

### 6. Référence de marché MASI (historique réel)
- `forecast.annualized_stats(frame)` : rendement annualisé, volatilité, période,
  à partir de l'historique **réel** de l'indice (dates et valeurs observées).
- `simulator._benchmark_reference()` : construit la trajectoire des mêmes versements
  placés au rythme historique du MASI.
- `charts.fan_chart(..., benchmark, benchmark_label)` : ajoute la ligne de référence.
- Si l'historique est indisponible : message explicite, **aucune performance inventée**.

## P3 — Portefeuille : journal d'opérations

### 7. Nouveau module `ecoinvest/portfolio/ledger.py`
- Types : `buy`, `sell`, `dividend`, `fee`, `deposit`, `withdrawal`.
- Validation stricte (`LedgerError`) : type, symbole, quantité > 0, prix ≥ 0,
  date `AAAA-MM-JJ`, frais ≥ 0.
- Calculs :
  - **coût moyen pondéré**, frais d'achat inclus dans le coût de revient ;
  - **plus-values réalisées** (ventes) et **latentes** (cours fournis) ;
  - **dividendes** et **frais** cumulés ;
  - **trésorerie** reconstituée à partir des seuls flux enregistrés.
- Une **vente supérieure à la position** est signalée, jamais corrigée en silence.
- Un **cours manquant** rend la plus-value latente indisponible (pas de zéro).
- Persistance locale : `data/user/transactions.json` (git-ignoré).

### 8. Interface
- `ecoinvest/ui/pages/portfolio_builder.py` : section « Journal d'opérations »
  - formulaire d'ajout, historique, suppression ;
  - KPI : valeur des positions, capital investi, plus-value latente/réalisée, trésorerie ;
  - avertissements si cours manquants ou vente excédentaire.

## P4 — Actualités et sécurité éditoriale

### 9. Garde-fou anti-artefacts LLM
- `ecoinvest/ai/llm.py` : `sanitize_llm_text()` appliqué à **toutes** les réponses
  des fournisseurs. Supprime les tournures corrompues du type « … classe est égale
  à … » et les lignes techniques `snake_case_key = valeur`. Le contenu rédigé est
  conservé ; si tout le texte est technique, un message explicite le remplace.
- `ecoinvest/ai/prompts.py` : les ratios et états financiers sont présentés en
  français (« Chiffre d'affaires : … ») au lieu de `clé = valeur`, ce qui réduit
  les régurgitations techniques.

### 10. Fautes de mots-clés
- `ecoinvest/data/news.py` : suppression de « dinamisme » et « bienefice ».

### 11. Bug de libellé technique
- `ecoinvest/ui/pages/parcours_page.py` : `summary["trend"]["label"]` → `["state"]`
  (la clé `label` n'existe pas ; la tendance s'affichait toujours indisponible).

## Limites restantes (assumées)

- **Couverture des états financiers** : toujours TMA (2023, 2024) et MOX (2024).
  Étendre la couverture exige une vérification manuelle document par document ;
  aucun montant n'est extrapolé.
- **Bank Al-Maghrib / HCP** : pas d'API publique documentée identifiée ; à intégrer
  via import validé ou page officielle documentée.
- **Paiement / abonnement** : aucun prestataire intégré ; aucune simulation de
  paiement réussi n'est présentée comme réelle.
- **Authentification** : l'application reste **locale mono-utilisateur** (décision
  explicite) ; le journal d'opérations n'est donc pas isolé par compte.
- **PDF scannés** : OCR non inclus.
- **Clé API** : `data/user/ai_config.json` contient une clé en clair, non commitée ;
  elle n'est jamais affichée par l'interface. La révocation reste à la charge de
  l'utilisateur.
