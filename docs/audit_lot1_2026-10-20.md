## 4. Bug prioritaire — « exercices 2023 et 2024 affichent les mêmes montants »

### Cause exacte
Dans le jeu vérifié `data/seed/bvc_statements.json`, le record **TMA 2023** avait ses
**lignes détaillées (`lines`) copiées de 2024** avec `prior: null`, alors que ses
**agrégats** (`income`, `balance`) étaient corrects. L'affichage lit `record["lines"]`
(`statements.block_table`), donc le tableau 2023 montrait les montants 2024 :

```
TMA 2023 · income.lines values[:3] = [18 194 103 791,28 , 153 922 230,8 , 18 348 026 022,08]  ← valeurs 2024
TMA 2023 · income.revenue (agrégat) = 17 984 198 998,17                                        ← valeur 2023
```

Deux défauts cumulés :
1. **Donnée** : détail 2023 erroné dans le seed.
2. **Robustesse** : aucune vérification ne comparait le détail aux agrégats, et les
   colonnes n'affichaient pas l'année, donc l'erreur était invisible.

### Correction appliquée
1. **Validation** — `statements.record_issues()` vérifie que chaque agrégat canonique
   (CA, résultat net, total actif, capitaux propres) apparaît bien dans le détail ;
   `statements.store_issues()` balaie tout le magasin. Sur le seed initial : **TMA 2023
   seul** était incohérent (contrôlé sur les 3 records).
2. **Donnée corrigée** — les lignes détaillées erronées de TMA 2023 sont retirées
   (agrégats vérifiés conservés) ; le tableau 2023 bascule alors sur le repli agrégats
   (`block_table`), qui affiche **les vrais montants 2023**. Aucune ligne n'est inventée :
   la colonne « exercice précédent » reste vide (pas de donnée 2022).
   *Note :* la colonne « comparatif 2023 » du rapport 2024 ne correspond pas à tous les
   agrégats 2023 (intérêts, créances diffèrent) — la recopier aurait été inexact, donc
   écarté.
3. **Affichage** — les colonnes sont renommées avec l'année réellement sélectionnée
   (`_exercise_columns` : « Exercice 2023 » / « Exercice 2022 »), un badge indique
   « Exercice 2023 · comptes sociaux · source », et un avertissement apparaît si un
   détail reste incohérent.

### Vérification
- Tests : `tests/test_statements_exercise.py` (8 tests) — les CA 2023 et 2024 diffèrent
  et valent 17,98 Md / 18,35 Md ; intégrité du magasin ; repli agrégats ; détection de
  détail erroné ; libellés de colonnes.
- Suite complète : **174 tests OK** (1 sauté, PDF AMMC hors cache).
- Navigateur : sélection 2023 → 17,98 Md ; 2024 → 18,35 Md ; colonnes « Exercice 2023/2024 ».
